High-Level Summary Before space agencies send rovers or astronauts to Mars or the Moon, they test their equipment on Earth in places with similar rocks, terrain, and weather—called Planetary Analog Sites. Old lists only cover a few famous locations. ANALOG//ATLAS turns the whole Earth into a live testing map. Anyone can explore 10 famous analog sites or click any spot on Earth to check how closely it matches 50 real Mars and Moon locations (25 on Mars and 25 on the Moon) in real time. By showing live Earth data side-by-side with real NASA orbital maps, our tool helps scientists and students find the best testing grounds on Earth. 2. Project Details Project Goals Replace static analog lists with live, real-time data for any spot on Earth. Show clear, easy-to-understand match scores alongside real Earth satellite and NASA planetary maps. Keep the app fast and reliable with automatic backup APIs and a 3-hour local cache. How Our Project Works (4 Simple Stages) 1. Stage 1 — The User Interface (index.html & styles.css): The left side shows a live interactive world map; the right side shows match score rings, weather cards, rock bars, and satellite photos. Clicking Earth, Mars, or Moon instantly changes the screen colors (Green, Cyan, or Purple) and updates the planetary match scores. 2. Stage 2 — The Live Data Collector (app.js): When you click any spot on Earth, our code calls four live APIs at the exact same time and saves the result for 3 hours so repeat clicks load instantly: Live Weather (OpenWeatherMap): Gets current temperature, humidity, air pressure, and country name. 1-Year Climate History (Open-Meteo ERA5): Checks 365 days of past weather to measure true annual dryness. 3D Height & Slope (OpenTopography): Downloads elevation grids to calculate how flat or steep the ground is. Underground Rocks (Macrostrat): Checks real geological maps to identify local rocks and minerals (basalt, iron oxides, sulfates, clays, and ice). Stage 3 — The Score Calculator (app.js): Using the live data, the code calculates an honest Analog Match Score from 10% to 99% with zero pre-typed guesses. It adjusts sea-level weather pressure to match mountain or valley height, blocks clicks in the ocean (water) as an Invalid Target while still allowing dry below-sea-level deserts, and lowers the score if the area is wet or lush green. 4. Stage 4 — Planetary Matcher & NASA Orbital Map (app.js): Compares your Earth spot against 25 Mars sites (like Jezero Crater and Olympus Mons) and 25 Moon sites (like Shackleton Crater and Mare Tranquillitatis), then opens a full-screen interactive Mars or Moon map side-by-side with Earth satellite imagery. Simple 5-Factor Score Formula (10%–99%): • 30% Dryness + 25% Rocks & Minerals + 15% Temperature + 15% Air Pressure + 15% Ground Slope (reduced automatically if the area is wet or lush green). Tools & Technologies Used Built with HTML5, CSS3, JavaScript, and Leaflet.js for interactive maps, using a 3-hour local browser cache and automatic backup APIs so the demo stays fast and never crashes on slow Wi-Fi. 3. Use of NASA Data ANALOG//ATLAS uses official NASA Solar System Treks and NASA Open API services to display real Mars and Moon surfaces: # 1 2 NASA Solar System Treks (trek.nasa.gov/tiles): Mars Maps: Loads real orbital mosaics (Viking Color Mosaic and MOLA Color-Shaded Relief) centered on the matched Mars site. Moon Maps: Loads real orbital mosaics (LRO WAC Mosaic and LOLA Color-Shaded Relief) centered on the matched Moon site. Interactive Planet Explorer: Fixes polar map stretching, hides blank dark orbital strips, and lets users zoom, pan, and click all 50 Mars and Moon landmarks in a full-screen planetary map. NASA Mars Rover Photos API (api.nasa.gov/mars-photos/api/v1/rovers): Works as an automatic backup that shows real Curiosity rover ground photos if map tiles fail to load. 4.
